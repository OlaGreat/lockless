# Lockless

Liquid veMEZO for Mezo Earn.

Deposit MEZO, or an existing veMEZO lock, and receive stMEZO: a liquid token backed 1:1 by MEZO held in one permanent veMEZO lock. The vault votes that lock every epoch, collects the incentives it earns and pays them to stMEZO stakers in MUSD.

Built for the Mezo Buildathon (Track 1: DeFi).
